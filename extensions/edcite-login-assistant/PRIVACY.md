# Privacy notice — Edcite Login Assistant

Edcite Login Assistant stores server URLs, usernames, encrypted passwords, account types, and redirect paths in Chrome extension local storage on the user's device. Passwords are encrypted locally with AES-GCM before storage and decrypted only in memory during login.

The extension does not operate a remote credential service and does not intentionally transmit stored credentials to the extension author. Credentials are used only to automate login on the Edcite server selected by the user.

Users should protect their browser profile and remove saved accounts before sharing the device. Removing the extension removes access to the extension's stored data according to Chrome's storage behavior.

This extension is independently developed and is intended for authorized users who have legitimate access to the configured Edcite environments.
