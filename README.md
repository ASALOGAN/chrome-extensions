# Chrome Extensions

A collection of Chrome Extensions built while learning and exploring modern Chrome Extension development.

## Goals

- Learn Chrome Extension development with Manifest V3
- Understand Chrome Extension architecture and APIs
- Build multiple independent extensions
- Experiment with frontend and full-stack architectures
- Explore AI-powered Chrome Extensions
- Build reusable components and utilities

## Repository Structure

- extensions/ - Individual Chrome Extensions
- shared/ - Reusable code shared between extensions
- docs/ - Architecture notes, guides, and learning documentation

## Tech Stack

- TypeScript
- JavaScript
- React
- Vite
- Chrome Extensions Manifest V3
- Chrome Extension APIs
- Node.js
- AWS
- AWS Bedrock

## Extensions

Extensions will be added here as they are built.

## Development

Each extension is intended to be independently developed, built, tested, and loaded into Chrome.
